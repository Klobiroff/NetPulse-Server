    Эксплуатация¶

    Эта страница описывает то, чем пользуются при работающем сервере: консольные команды, метрики, логи и список проверок для типичных проблем.

    Консольные команды¶

    Консоль читает по одной команде в строке из стандартного ввода, пока NetPulse:EnableConsole равен true.

    Команда Что делает
    stats Печатает время работы, счётчики, загруженные плагины и открытые комнаты.
    plugins Перечисляет загруженные плагины и число комнат, которые каждый из них использует.
    reload <folder> Перезагружает плагин из указанной подпапки каталога плагинов. Печатает reloaded или reload failed.
    quit или exit Корректно останавливает сервер.

    На любую другую команду выводится Unknown command. Available: stats, plugins, reload <folder>, quit.

    stats¶

    uptime      0.00:12:31
peers       2
rooms       1
msgs in/out 1542 / 3120
bytes in/out 84210 / 160388
plugin errs 0
plugin      NetPulse.Plugins.Sample v1 (rooms: 1)
room        test 2/2 open=True

    msgs и bytes считают сообщения и байты, которые сервер получил и отправил с момента запуска. plugin errs считает исключения в коде плагинов (см. Хуки). Тайм-ауты хуков пишутся в лог, но здесь не учитываются. Число rooms: 1 после плагина показывает, сколько комнат сейчас работает на нём. В строки room попадают и комнаты, скрытые из списка лобби.

    plugins¶

    NetPulse.Plugins.Sample v1 leases=1

    leases показывает число комнат, использующих эту версию плагина. При горячей перезагрузке старая версия остаётся загруженной, пока счётчик не дойдёт до нуля.

    reload¶

    reload MyPlugin принимает имя папки, а не имя плагина из plugin.json. Если папки больше нет, плагин выгружается, но команда всё равно печатает reload failed, потому что загружать нечего.

    Метрики¶

    Сервер публикует метрики через System.Diagnostics.Metrics под именем метра NetPulse.

    Инструмент Вид Значение
    netpulse.peers gauge Подключённые пиры.
    netpulse.rooms gauge Существующие комнаты.
    netpulse.msgs_in counter Сообщения, полученные от клиентов.
    netpulse.msgs_out counter Сообщения, отправленные клиентам.
    netpulse.peers_overloaded counter Пиры, отключённые за превышение лимитов очередей (причина Overloaded).
    netpulse.ownership_violations counter Операции с сетевыми объектами, отклонённые проверкой владения.

    Следить за ними вживую можно утилитой dotnet-counters:

    dotnet-counters monitor --counters NetPulse --name NetPulse.Server

    dotnet-counters и сборщики OpenTelemetry умеют читать любой Meter. Собственного экспортёра у сервера нет: чтобы отправлять метрики в систему мониторинга, добавьте экспортёр в код своего хоста.

    Логи¶

    Сервер пишет однострочные сообщения в стандартный вывод через обычную настройку Logging. Файла лога нет: собирайте вывод средствами менеджера служб (journalctl -u netpulse, драйвер логов Docker или перенаправление).

    info: NetPulse.Lobby[0] Creating room arena for user42
info: NetPulse.Room.arena[0] Room arena closed

    Категория показывает, откуда пришло сообщение: NetPulse.Lobby, NetPulse.Room.<имя комнаты>, NetPulse.Flood и имена классов серверных компонентов. Плагины пишут через Host.Logger, который использует категорию комнаты.

    Сообщения, которые стоит знать:

    Уровень Сообщение Значение
    Warning Disconnecting peer N (room X): exceeded its limit of 256 queued messages Клиент отправлял быстрее, чем комната успевала обрабатывать. См. PeerQueueLimit.
    Warning Queue of room X is full; dropping a message from peer N Очередь комнаты достигла RoomQueueCapacity.
    Warning Malformed packet from peer N: ... Пакет не удалось разобрать. Обычно это несовпадение клиента и протокола.
    Warning Rejected object operation from actor N in room X: ... Проверка владения отклонила сообщение. Пишется не чаще раза в секунду на игрока.
    Warning Plugin hook P timed out after 00:00:05 in room X Хук превысил HookTimeoutMs.
    Error Exception in plugin code of room X Исключение в хуке, таймере или отложенном действии.
    Error Plugin hook returned without calling Continue/Fail in room X; treating as Fail Хук завершился, не приняв решения.
    Warning Plugin hook H was already completed as ...; ignoring ... Хук вызвал Continue, Fail или Cancel дважды либо после тайм-аута.
    Error Failed to load plugin from F; keeping previous version if any Загрузка или перезагрузка не удалась. Ниже идёт исключение.
    Warning Authentication plugin timed out for peer N IAuthPlugin превысил AuthTimeoutMs.
    Warning Not all rooms closed within 00:00:10 При остановке не хватило времени.

    Сообщения о подключении и отключении пишутся на уровне Debug. Чтобы их увидеть, поставьте Logging:LogLevel:Default в Debug.

    Решение проблем¶

    Клиенты не могут подключиться¶

    • Убедитесь, что сервер записал listening on UDP <port> и что порт совпадает с настройками клиента.
    • Разрешите входящий UDP на этом порту во всех файрволах и облачных группах безопасности. См. Развёртывание.
    • Несовпадение ключа подключения: сервер молча отклоняет клиента, ключ которого отличается от NetPulse:ConnectionKey.
    • Достигнут NetPulse:MaxConnections: новые подключения отклоняются. Сверьтесь с netpulse.peers.
    • В Docker пробрасывайте порт как 5055:5055/udp.

    Подключение есть, но аутентификация не проходит¶

    Код Причина
    InvalidAppId (-31) AppId клиента отличается от NetPulse:AppId.
    VersionMismatch (-30) Клиент говорит на другой версии протокола. Обновляйте пакет и сервер вместе или поставьте AppVersionCheck в false, чтобы пропустить проверку.
    AuthenticationFailed (-32) Плагин аутентификации отклонил клиента, не уложился в срок или сломался. Вскоре сервер отключает клиента. Причина указана в сообщении.
    NotAuthenticated (-3) Клиент отправил другую операцию до аутентификации.

    Плагин не найден или не загружается¶

    • PluginNotFound (-21) с сообщением Plugin 'X' is not installed: комната запросила плагин, который не загружен. Имя должно совпадать с name в plugin.json, а в папке должен лежать этот файл. Тот же код с текстом provides no room plugin означает, что в манифесте нет factory.
    • В логе запуска нет строки Loaded plugin: запустите с Logging:LogLevel:Default на уровне Debug. Папка без plugin.json попадает в лог как пропущенная.
    • Failed to load plugin from ...: прочитайте исключение под сообщением. Типичные причины: неверное имя assembly или factory, отсутствие зависимости в папке плагина.
    • PluginReportedError (-20) при создании комнаты или входе с сообщением вроде Plugin hook timed out, Plugin did not respond или Plugin error: хук завершился ошибкой. Подробности в логе сервера. См. Хуки.

    Клиентов отключают с причиной Overloaded¶

    Пир отправил больше PeerQueueLimit сообщений, которые комната ещё не обработала. Либо клиент шлёт слишком много сообщений в секунду, либо комната медленная, потому что хук плагина ждёт ввода-вывода. Проверьте netpulse.peers_overloaded и предупреждения выше. Сначала исправьте медленный хук, а лимит повышайте, только если трафик законный.

    Комната не закрывается или не обновляется¶

    • EmptyRoomTtlMs держит пустую комнату живой указанное время, а PlayerTtlMs оставляет вышедшего игрока неактивным. Оба параметра задаются в опциях комнаты на клиенте.
    • Плагин, который отменяет или проваливает OnBeforeCloseRoomAsync, не даёт опустевшей комнате закрыться. Остановка сервера это игнорирует и закрывает комнату в любом случае.
    • Хук, который никогда не завершается, блокирует свою комнату до истечения HookTimeoutMs. Остальные комнаты продолжают работать.

    Изменение плагина не действует¶

    Горячая перезагрузка ждёт полсекунды после последнего изменения файла. Новые комнаты получают новую версию, работающие остаются на старой. Если перезагрузка не удалась, остаётся предыдущая версия. Выполните reload <folder> и прочитайте лог. См. Горячая перезагрузка.

    Игроки отваливаются примерно через десять секунд¶

    Пир, который ничего не присылает, отключается через NetPulse:DisconnectTimeoutMs (10 секунд). На клиенте это обычно значит, что связь потеряна или игра была приостановлена (например, точкой останова отладчика) настолько долго, что служебные сообщения не дошли.
