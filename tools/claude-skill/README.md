# Claude Code skill: integrating-netpulse

`integrating-netpulse` teaches Claude Code how to add NetPulse multiplayer to a Unity game or move a Photon PUN project to NetPulse. It contains the integration steps, the common mistakes and an API reference with a worked example that compiles against package 0.4.0.

## Install

Copy the `integrating-netpulse` folder into your personal skills folder:

- Windows: `%USERPROFILE%\.claude\skills\`
- macOS and Linux: `~/.claude/skills/`

To share it with a team, copy it into `.claude/skills/` of the game project instead. Claude Code picks it up the next time a session starts.

## Updating

When the NetPulse API changes, update `reference.md` and compile the worked example against the new package before you publish the skill.
