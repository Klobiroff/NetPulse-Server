# Конфигурация

Все параметры находятся в секции `NetPulse`. Сервер читает `appsettings.json` из рабочей папки, затем переменные окружения, затем командную строку. Синтаксис каждого источника описан в разделе [Запуск сервера](running.md#changing-settings).

В поставляемом `appsettings.json` заданы лишь несколько значений, а остальные параметры принимают значения по умолчанию из таблиц ниже.

## Сеть и ёмкость

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NetPulse:Port` | `5055` | UDP-порт, который занимает сервер. `0` выбирает случайный свободный порт, его печатает лог запуска. |
| `NetPulse:ConnectionKey` | `NetPulse` | Ключ подключения LiteNetLib. Клиент с другим ключом отклоняется ещё до того, как успеет что-то отправить. Unity-клиент использует то же значение по умолчанию, и в его настройках есть соответствующее поле. |
| `NetPulse:MaxConnections` | `2000` | Максимальное число подключённых пиров. Новые запросы на подключение сверх лимита отклоняются. |
| `NetPulse:TickRate` | `30` | Частота обновления транспорта в тиках в секунду (интервал равен `1000 / TickRate` мс, не меньше 1 мс). Значение также уходит каждому клиенту в ответе на вход, и Unity-клиент использует его для сетевого тика. Значения меньше 1 считаются равными 1. |
| `NetPulse:DisconnectTimeoutMs` | `10000` | Пир, который ничего не присылает так долго, отключается. |
| `NetPulse:RoomListIntervalMs` | `1000` | Как часто лобби отправляет подписанным клиентам изменения списка комнат. Значения меньше 50 считаются равными 50. |

## Проверки приложения

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NetPulse:AppId` | пусто | Если задан, каждый клиент обязан прислать в запросе аутентификации в точности этот AppId, иначе получит `InvalidAppId` (-31). Если пуст, принимается любой AppId. |
| `NetPulse:AppVersionCheck` | `true` | При `true` версия протокола от клиента должна совпадать с версией сервера (сейчас `1`), иначе клиент получит `VersionMismatch` (-30). Проверяется версия протокола, а не строка `AppVersion` вашей игры. |

AppId не является секретом, потому что поставляется внутри игры. Он нужен, чтобы разделять несвязанные игры и тестовые сборки, а решать, кому играть, помогает [аутентификация](../plugins/authentication.md). См. [Безопасность](security.md).

## Защита от флуда и тайм-ауты

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NetPulse:PeerQueueLimit` | `256` | Максимум сообщений одного пира, которые стоят в очереди и ещё не обработаны, суммарно по лобби и комнате. Когда пир превышает лимит, сообщение отбрасывается, а пир отключается с причиной `Overloaded`. Значения меньше 1 считаются равными 1. |
| `NetPulse:RoomQueueCapacity` | `4096` | Жёсткая граница сообщений пиров в очереди одной комнаты и отдельно лобби. При переполнении новое сообщение отбрасывается, а отключается пир с наибольшим числом сообщений в этой очереди. Это не обязательно тот, кто только что отправил. Работа, которую сервер ставит в очередь сам (таймеры, `Host.Enqueue`, остановка), в лимит не входит. Значения меньше 1 считаются равными 1. |
| `NetPulse:OwnershipRequestTimeoutMs` | `5000` | Сколько запрос владения для объекта в режиме `Request` ждёт одобрения владельца, прежде чем истечь. Значения меньше 1 считаются равными 1. |
| `NetPulse:ShutdownTimeoutMs` | `10000` | Бюджет времени на закрытие всех комнат при остановке сервера. |

## Шифрование {#encryption}

Шифрование транспорта настраивается в `NetPulse:Encryption`. Значение по умолчанию `Disabled` ничего не устанавливает и оставляет формат на проводе прежним. Что означают режимы — в разделе [Безопасность](security.md#transport-encryption), как менять ключи — в разделе [Развёртывание](deployment.md#rotating-the-server-key).

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NetPulse:Encryption:Mode` | `Disabled` | `Disabled`, `Optional` (открытые и шифрованные клиенты) или `Required` (только шифрованные). При `Optional` и `Required` сервер не запустится без корректного приватного ключа. |
| `NetPulse:Encryption:PrivateKeyFile` | пусто | Файл с приватным ключом в Base64, созданный командой `NetPulse.Server keygen`. Относительный путь считается от папки с бинарником сервера. Используйте его или переменную `NETPULSE_SERVER_PRIVATE_KEY`, но не оба сразу. |
| `NetPulse:Encryption:PreviousPrivateKeyFiles` | пустой список | Выведенные из обращения приватные ключи, которые ещё принимаются, чтобы клиенты с закреплённым старым публичным ключом работали во время ротации. |
| `NetPulse:Encryption:PreSharedKey` | пусто | Необязательный ключ в Base64 (32 байта), который должен быть и у каждого клиента. |
| `NetPulse:Encryption:PreSharedKeyFile` | пусто | То же, но из файла. Задавайте не больше одного из двух. |
| `NetPulse:Encryption:RequireCookie` | `true` | Требовать от клиента вернуть cookie, прежде чем сервер начнёт обмен ключами. Отключайте только в закрытой сети: без этого пропадает защита от подмены отправителя. |
| `NetPulse:Encryption:CookieLifetimeMs` | `30000` | Как часто меняется секрет cookie (предыдущий тоже принимается). Не меньше 1000. |
| `NetPulse:Encryption:RekeyAfterPackets` | `1000000` | Менять ключ отправки после стольких пакетов. `0` выключает условие по пакетам. |
| `NetPulse:Encryption:RekeyAfterMs` | `600000` | Менять ключ отправки по прошествии стольких миллисекунд. `0` выключает условие по времени. |
| `NetPulse:Encryption:ReplayWindow` | `4096` | Размер окна защиты от повтора в пакетах. Кратно 64, от 64 до 65536. |
| `NetPulse:Encryption:SessionIdleTimeoutMs` | `30000` | Сессия, в которой столько времени не было корректных пакетов, удаляется, а её пир отключается. Не меньше 1000. |
| `NetPulse:Encryption:ReplaceIdleMs` | `3000` | Сколько сессия должна молчать, чтобы новое рукопожатие с того же адреса могло её заменить. |
| `NetPulse:Encryption:HandshakeTimeoutMs` | `5000` | Сколько хранится незавершённое рукопожатие. Не меньше 500. |
| `NetPulse:Encryption:PaddingBlock` | `0` | Дополнять каждую исходящую запись до кратной этому числу байтов длины. `0` — выключено, иначе от 16 до 512. |

## Лимиты {#limits}

Секция `NetPulse:Security` содержит лимиты против злоупотреблений. `0` выключает лимит. Смысл каждого ключа, значение по умолчанию и последствия нарушения указаны в таблице раздела [Безопасность](security.md#limits-for-connected-clients).

| Ключ | По умолчанию |
|---|---|
| `MaxConnectionsPerIp` | `32` |
| `ConnectionAttemptsPerIpPerSecond` | `20` |
| `HandshakesPerIpPerSecond` | `10` |
| `MaxHandshakesPerSecond` | `2000` |
| `AuthDeadlineMs` | `10000` |
| `MaxAuthAttempts` | `5` |
| `MaxMessagesPerSecond` / `MessageBurst` | `1000` / `2000` |
| `MaxBytesPerSecond` / `ByteBurst` | `1048576` / `2097152` |
| `MaxMessageBytes` | `262144` |
| `MaxUserIdLength` / `MaxNickNameLength` / `MaxAuthTokenLength` | `128` / `64` / `8192` |
| `MaxRoomNameLength` | `128` |
| `MaxPropertiesPerRoom` / `MaxPropertyBytes` | `256` / `16384` |
| `MaxCachedEventsPerRoom` / `MaxTargetActors` | `4096` / `256` |
| `RequireRejoinToken` | `false` |

Отрицательное значение не даст серверу запуститься.

## Консоль

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NetPulse:EnableConsole` | `true` | Читать команды из стандартного ввода. Отключите, если у процесса нет консоли, например под менеджером служб. |

## Плагины

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NetPulse:Plugins:Directory` | `plugins` | Папка, где каждый плагин лежит в своей подпапке. Относительный путь отсчитывается от папки бинарника сервера, абсолютный используется как есть. Если папки нет, сервер её создаёт. |
| `NetPulse:Plugins:Default` | пусто | Плагин для комнат, которые не указали его в `RoomOptions.Plugin`. Пусто означает, что такие комнаты работают без плагина. |
| `NetPulse:Plugins:Auth` | пусто | Имя плагина, который отвечает за аутентификацию (`IAuthPlugin`). Если параметр задан, а плагин не загрузился, сервер отказывается запускаться. Пусто означает отсутствие аутентификации: принимается любой клиент. |
| `NetPulse:Plugins:HotReload` | `true` | Следить за папкой плагинов и перезагружать плагин при изменении его файлов. См. [Горячая перезагрузка](../plugins/hot-reload.md). |
| `NetPulse:Plugins:HookTimeoutMs` | `5000` | Сколько времени отводится хуку плагина или его фабрике. Вызов, не уложившийся в срок, завершается ошибкой с предупреждением в логе. Значения меньше 1 считаются равными 1. |
| `NetPulse:Plugins:AuthTimeoutMs` | `5000` | Сколько времени отводится `IAuthPlugin.AuthenticateAsync`. По истечении клиент получает `AuthenticationFailed` (-32) и отключается. Значения меньше 1 считаются равными 1. |
| `NetPulse:Plugins:Settings:<Plugin>:<key>` | нет | Строковые настройки, которые попадают в фабрику плагина как словарь `config`. `<Plugin>` берётся из `name` в `plugin.json`, регистр не учитывается. Ключи настроек сохраняют написание, а поиск в словаре внутри плагина учитывает регистр. |

В поставляемом файле пример плагина настроен так:

```json
{
  "NetPulse": {
    "Plugins": {
      "Settings": {
        "NetPulse.Plugins.Sample": {
          "ScorePerPoint": "1"
        }
      }
    }
  }
}
```

Пример плагина также читает `JoinCheckDelayMs` (по умолчанию `10`): задержку в миллисекундах для проверки при входе.

## Логирование

Логирование использует стандартную секцию `Logging` и пишет однострочные сообщения в консоль. В поставляемом файле уровень по умолчанию равен `Information`, а категории `Microsoft` имеют уровень `Warning`. Чтобы видеть сообщения о подключении и отключении, поставьте `Logging:LogLevel:Default` в `Debug`. См. [Эксплуатация](operations.md#logs).

## Полный пример

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft": "Warning"
    }
  },
  "NetPulse": {
    "Port": 5055,
    "ConnectionKey": "NetPulse",
    "MaxConnections": 2000,
    "AppId": "my-game",
    "AppVersionCheck": true,
    "TickRate": 30,
    "DisconnectTimeoutMs": 10000,
    "RoomListIntervalMs": 1000,
    "PeerQueueLimit": 256,
    "RoomQueueCapacity": 4096,
    "OwnershipRequestTimeoutMs": 5000,
    "ShutdownTimeoutMs": 10000,
    "Encryption": {
      "Mode": "Required",
      "PrivateKeyFile": "server.key",
      "PaddingBlock": 0
    },
    "Security": {
      "MaxConnectionsPerIp": 32,
      "MaxMessagesPerSecond": 1000,
      "MaxMessageBytes": 262144,
      "RequireRejoinToken": false
    },
    "EnableConsole": false,
    "Plugins": {
      "Directory": "plugins",
      "Default": "MyPlugin",
      "Auth": "AuthSample",
      "HotReload": true,
      "HookTimeoutMs": 5000,
      "AuthTimeoutMs": 5000,
      "Settings": {
        "AuthSample": {
          "Mode": "Hmac",
          "Secret": "change-me-long-random-string"
        },
        "MyPlugin": {
          "Greeting": "Welcome"
        }
      }
    }
  }
}
```

!!! note
    Настройки плагина всегда приходят в плагин строками. Числа и булевы значения разбирайте в фабрике.
